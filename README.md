
# Αναγνώριση Ελληνικών Παραδοσιακών Φορεσιών

Πτυχιακή εργασία με αντικείμενο την αναγνώριση ελληνικών παραδοσιακών φορεσιών από εικόνες, με αξιοποίηση τεχνικών βαθιάς μάθησης (Deep Learning).

Η εφαρμογή αναπτύχθηκε με **Python**, **PyTorch** και **Flask**. Ο χρήστης μπορεί να ανεβάσει μια εικόνα παραδοσιακής φορεσιάς και να δει τις **τρεις πιθανότερες γεωγραφικές περιοχές** που προβλέπει το εκπαιδευμένο μοντέλο, μαζί με τα αντίστοιχα ποσοστά πιθανότητας.

## Μοντέλο αναγνώρισης

Η τρέχουσα έκδοση της εφαρμογής χρησιμοποιεί την αρχιτεκτονική **ConvNeXt Tiny**, με checkpoint που αποθηκεύεται ως `convnext_tiny_partial_fine_tuning.pth`.

Οι προβλέψεις αφορούν εννέα γεωγραφικές κατηγορίες:

- Ήπειρος
- Κρήτη
- Μακεδονία
- Νησιά Αιγαίου
- Νησιά Ιονίου
- Πελοπόννησος
- Στερεά Ελλάδα
- Θεσσαλία
- Θράκη

Η εικόνα προεπεξεργάζεται με αλλαγή μεγέθους και κανονικοποίηση και περνά στο μοντέλο για πρόβλεψη. Οι έξοδοι μετατρέπονται σε πιθανότητες με τη συνάρτηση `softmax` και εμφανίζονται οι τρεις υψηλότερες τιμές (Top-3).

Τα ποσοστά εκφράζουν τις εκτιμήσεις του μοντέλου και δεν αποτελούν εγγύηση ορθότητας.

## Απαιτήσεις

Για την εκτέλεση της εφαρμογής απαιτούνται:

- Εγκατεστημένη Python 3 και `pip`, σε έκδοση συμβατή με τις βιβλιοθήκες του `requirements.txt`.

- Το εκπαιδευμένο αρχείο του μοντέλου στην προβλεπόμενη διαδρομή.

Η εφαρμογή μπορεί να εκτελεστεί σε **CPU** ή, εφόσον υπάρχει συμβατή **GPU με CUDA**, να χρησιμοποιήσει αυτήν για την εκτέλεση του μοντέλου.

Δεν χρειάζεται να περιλαμβάνεται έτοιμος φάκελος `.venv` στο repository, καθώς το εικονικό περιβάλλον δημιουργείται τοπικά στον υπολογιστή όπου θα εκτελεστεί η εφαρμογή.

## Εγκατάσταση και εκτέλεση

Οι παρακάτω οδηγίες αφορούν υπολογιστή με λειτουργικό σύστημα Windows.

Ανοίξτε PowerShell ή Command Prompt μέσα στον βασικό φάκελο του project.

### 1. Δημιουργία εικονικού περιβάλλοντος

```powershell
python -m venv .venv
```

### 2. Ενεργοποίηση εικονικού περιβάλλοντος

Σε Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Σε Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

### 3. Εγκατάσταση απαιτούμενων βιβλιοθηκών

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Εκκίνηση της εφαρμογής

```powershell
python app.py
```

Μετά την εκκίνηση, ανοίξτε τη διεύθυνση:

http://127.0.0.1:5000

Η εφαρμογή θα εμφανιστεί στο πρόγραμμα περιήγησης.

**Σημείωση:** Η εφαρμογή προορίζεται για τοπική εκτέλεση και δοκιμή. Εάν χρησιμοποιείται η ρύθμιση `debug=True`, δεν πρέπει να εκτίθεται ως έχει σε δημόσιο περιβάλλον παραγωγής.

## Σημαντική σημείωση για το μοντέλο

Για να λειτουργήσει η αναγνώριση, πρέπει να υπάρχει το εκπαιδευμένο αρχείο στη διαδρομή:

```text
models/trained/convnext_tiny_partial_fine_tuning/convnext_tiny_partial_fine_tuning.pth
```

Το αρχείο φορτώνεται από το `model.py` κατά την εκκίνηση της εφαρμογής.

Αν δεν υπάρχει στη συγκεκριμένη θέση, η εφαρμογή δεν θα μπορέσει να φορτώσει το μοντέλο.

Σε περίπτωση που το checkpoint δεν περιλαμβάνεται στο repository λόγω μεγέθους, θα πρέπει να δοθεί ξεχωριστά και να τοποθετηθεί στην παραπάνω διαδρομή.
